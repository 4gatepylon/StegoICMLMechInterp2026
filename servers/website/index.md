# The Stego Challenge

**$1,024 in prizes over 4 days.**

We trained a language model to write Python programs that look ordinary but secretly encode hidden bitstrings. Your job: figure out **how**.

## What you know

- Each program below is valid, runnable Python.
- Each program encodes a secret bitstring. The encoding is entirely in the source text — the program's runtime behavior is irrelevant.
- The encoding scheme is deterministic: given the same source code, the same bitstring is always recovered.
- The scheme operates on **syntactic features** of the source code. No comments, strings, or whitespace carry signal.
- All programs were generated by the same encoding scheme.

## What you need to find

The exact encoding rule that maps a Python source file to its hidden bitstring. Once you think you've cracked it, use the [verification API](submit) to check your work.
